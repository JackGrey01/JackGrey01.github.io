# Final Project Scope Statement

## Project Overview

For Project 03 I will build a small professional website that expands on the work I have already done earlier in the course. The main goal is to give someone visiting the site a solid idea of what my background is, what I am currently working towards, and where I want to end up professionally.

The website will include my previous experience in military intelligence and law enforcement, along with with my current Computing Applications degree I'm working towards as well as my interest in moving further into IT and cybersecurity. I also plan to work towards the CompTIA A+, Network+, and Security+ certifications, so I want the site to reflect that direction and show the skills and goals I am building towards.

I also want the website to show a little bit of who I am outside of work and school. The About page can include some of my interests, such as Judo, without taking away from the professional purpose of the site.

I don't want to turn this into a huge portfolio with unnecessary additions; as I would rather keep it simple, very organized, and easy for someone to look through.

## Deliverables

The project will include:

1. A public GitHub repository containing the website and the required documentation for the project.

2. It will have a homepage named index.html that will introduce the site and give an overview of my background and professional goals.
 
3. I will have a second page named about.html that goes more into detail about my experience, education, interests, certification goals, and future plans.

4. There will be navigation between index.html and about.html.

5. An external stylesheet named style.css that is used by both pages so there is a consistent look throughout the website.

6. Organized HTML using headings, paragraphs, lists, links, images, and other elements whereever they make sense. I will also use appropriate semantic HTML elements where I possibly can.

7. Images or other visual content that support the site without it being too cluttered. Images that need any alternative text will include it.

8. A README.md file that will explain what the project is and include links to both the live website and documentation folder.

9. A 'docs' folder containing the project management documents required for Project 03.

10. The final 'docs' folder will include:

    - scope.md for the revised scope statement.
    - plan.md for the project plan, TAME risk analysis, and a very simple Work Breakdwon Structure task schedule
    - retrospective.md for the final reflection on what worked and what didn't as well as what I would change.

11. A live version of the site that can be opened through the published URL.

The project will be complete when both pages load correctly, have proper navigation between pages, the stylesheet is displaying appropriately throughout, the required documentation is included, and the overall site is working as expected.

## Out of Scope

I won't be building a backend, database, any login system, or other features outside of the very basic website requirements.

The site will not include like social networking features, live chat, or anything like online payments.

I am not planning to add any JavaScript features, animations, or any other complicated features unless they are required at a later time for the project.

I don't want the site to be a complete history of absolutely everything I've done in my professional career. I only want "wavetops" and the information that helps explain my background and goals. Anything sensitive or unnecessary won't be included in it.

I don't plan to keep adding pages or features just because they may sound interesting to implement. If something new comes up, I will decide if it actually adds value to the site and if it's worth implementing.

## Constraints and Assumptions

### Time

The project will have to be completed within the course schedule. I am both working and taking other courses so I will need to keep the project within realistic constraints. The pages, documentation, testing, and any fixes will come before optional features I could potentially add later.

### Quality

The website should be easy to read, organized as well as functional. The navigation between pages should work consistently and there should not be any broken elements or layout issues for the site. I don't expect it to look like a fully professional website. However, I do want it to show clear improvement from my earlier work and show what I have learned about HTML, CSS, GitHub, and project management compared to what I knew towards the beginning of the course

### Budget

I don't plan on spending any money whatsoever on this project. I will use tools and resources that were provided throughout the course or any that are completely free. I currently do not anticipate having to purchase software or any other services for the site.

### Assumptions

I am assuming that all resources used throughout the course will still be available in order to finish the project. I am also assuming that none of the requirements will change between now and when the assignment is due. Since this is a project for one person, I will be responsible for everything including the planning, development, testing and final submission.
