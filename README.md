# Jackson Thomas Personal Introduction Website

## About This Project

This repository contains the personal introduction website I created for my CMPA 3301 Fundamentals of Computing Applications class at Texas Tech. The page gives a very brief overview of my previous experience as an Army intelligence analyst/sergeant, my current work in digital forensics, and my goal of entually transition into IT or cybersecurity. It also includes some of my personal interests including judo, video games, history, and outer space.

This project takes both the HTML and CSS webpage I created during earlier work in the course and places it into a GitHub repository. The project gives me practice using commits to document all of the changes and using GitHub Pages to make a website accessible by the public.
