# Project Change Request

## Proposed Change

Add an embedded Google Map to the existing website that shows my hometown. The map would be placed somewhere that makes sense with the content already on the page instead of just being added because it is another feature. The goal would be to give visitors a visual reference for the location without changing the main purpose of the website.

## Reasons for the Change

The stakeholder is requesting the map so visitors can get a better understanding of where I a am from. As of now, the information would mostly have to be explained through text. A map would give the user another way to understand the location and could make that part of the site slightly more useful.

## How This Change Will Add Value

I think the map could add value because some information just makes more sense when you can actually see where the location is. It would also add some variety to the page withou redesigning it completely. Since this is a small feature it could improve the user experience without taking the site in a different direction.

## How This Change Will Affect the Constraints

### Time

I would probably expect this change to take about 30-45 minutes. I would need to decide where the map would fit best, add the embed code and test it to ensure that it works correctly. It could take slightly longer if I run into any layout issues along the way.

### Quality

The map could improve the overall quality of the website by adding useful visual information. If made too large however, it could make the page look potentially worse. It could also look worse if it has resizing issues or clashes with the rest of the design. I'd need to test it on multiple screen sizes to make sure it fits with the layout before considering it complete.

### Budget

I don't expect this change to add any additional cost financially if I just incorporate Google Maps. The only cost I can think of would be time needed to add it.
